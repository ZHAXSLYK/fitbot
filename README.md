# Фитнес-бот: зал + ПП на Термомиксе

Что умеет:
- 🎯 считает норму КБЖУ на сброс жира и сам пересчитывает её, когда средний вес уходит на 2 кг;
- 🏋️ ведёт по программе: 3 р/нед — фулбади A/B/C, 4 р/нед — верх/низ; «✅ сделана» двигает к следующей;
- 📅 меню на каждый день недели с кнопками рецептов и напоминанием о дне заготовок;
- 🍲 20 ПП-рецептов под Термомикс — те же номера, что в «Книге ПП-рецептов»;
- 🛒 список покупок на неделю;
- 📷 дневник питания: пришли **фото еды** — бот распознает блюда, оценит граммы и КБЖУ и запишет; или текстом `/eat гречка 200 г`, или числом `/eat 450`; кнопка «🍽 Съел порцию» у каждого рецепта;
- 🍽 дневник за день с остатком до нормы, итоги вчерашнего дня в утреннем плане, средние калории в «Прогрессе»;
- ✨ новые ПП-рецепты для Термомикса от AI без ограничений (кнопка в меню «🍲 Рецепт»);
- ⚖️ вес: просто пришли число — бот запишет и покажет тренд;
- ☀️ каждое утро — план дня (`/remind off` — выключить);
- 🤖 AI-тренер: бесплатно на Gemini или Groq, либо на Claude (платно).

---

## Установка бесплатно на PythonAnywhere (≈15 минут, лучше с компьютера)

Деньги и банковская карта не нужны. Бот будет работать круглосуточно.

### Шаг 1. Создай бота в Telegram
1. Найди в Telegram **@BotFather** → отправь `/newbot`.
2. Придумай имя (например «Мой тренер») и логин, оканчивающийся на `bot` (например `jax_fit_bot`).
3. BotFather пришлёт **токен** вида `123456789:AAH...` — скопируй его.

### Шаг 2. Зарегистрируйся на PythonAnywhere
1. Открой **pythonanywhere.com** → **Pricing & signup** → **Create a Beginner account** (бесплатный).
2. Укажи логин, email, пароль. Подтверди почту.

### Шаг 3. Загрузи бота
1. Вкладка **Files** → кнопка **Upload a file** → выбери `fitbot.zip`.
2. Вкладка **Consoles** → **Bash**. В открывшейся консоли выполни по очереди:
   ```bash
   unzip fitbot.zip
   cd fitbot
   pip3.12 install --user -r requirements.txt
   ```

### Шаг 4. Создай веб-приложение
1. Вкладка **Web** → **Add a new web app** → **Next**.
2. Выбери **Manual configuration** (не Flask!) → **Python 3.12** → **Next**.

> Если Python 3.12 в списке нет — выбери самую новую версию и везде ниже пиши её вместо `3.12`
> (например `pip3.13`, `python3.13`).

### Шаг 5. Запусти мастер установки
Вернись в консоль Bash (вкладка Consoles) и выполни:
```bash
cd ~/fitbot
python3.12 setup.py
```
Вставь токен из шага 1 и нажми Enter на остальных вопросах. Мастер сам всё подключит.

### Шаг 6. Включи
Вкладка **Web** → зелёная кнопка **Reload**. Открой своего бота в Telegram → `/start`. Готово!

### Шаг 7. Утренний план дня
Вкладка **Tasks** → в поле времени поставь **02:30** (это время UTC = 07:30 в Алматы) → в команду вставь:
```bash
python3.12 /home/ТВОЙ_ЛОГИН/fitbot/morning.py
```
→ **Create**.

### AI-тренер (бесплатно, по желанию)
1. Открой **aistudio.google.com** → войди Google-аккаунтом → **Get API key** → **Create API key** → скопируй.
2. В консоли Bash: `cd ~/fitbot && python3.12 set_key.py` → выбери `1` → вставь ключ.
3. Вкладка **Web** → **Reload**. Кнопка «🤖 Спросить тренера» заработает.

Можно вместо Gemini взять Groq (console.groq.com, тоже бесплатно) или Claude (платно) — `set_key.py` спросит, какой.
Бесплатный Gemini: Google может использовать вопросы для улучшения своих моделей — не пиши туда ничего личного.

### Раз в 3 месяца
Бесплатный сайт нужно продлевать: вкладка **Web** → кнопка **Run until 3 months from today**.
PythonAnywhere пришлёт письмо-напоминание. Задачи на вкладке Tasks тоже могут попросить продления — там будет кнопка.

## Если что-то не работает
- Бот молчит → вкладка **Web** → **Error log** (внизу страницы). Скопируй последние строки и пришли в чат с Claude.
- Поменял что-то в файлах → вкладка **Web** → **Reload**.
- Переустановить заново → снова `python3.12 setup.py`, потом **Reload**.
- AI-тренер отвечает «перегружен» — это лимит бесплатного тарифа Gemini, подожди минуту.

## Запуск на своём компьютере (для проверки)
Нужен Python 3.10+. В папке бота:
```bash
pip install -r requirements.txt
cp .env.example .env      # впиши BOT_TOKEN
python run_local.py
```
Бот работает, пока открыта эта программа. Не запускай одновременно с PythonAnywhere — `run_local.py` отключает вебхук; чтобы вернуть бота на PythonAnywhere, снова выполни там `python3.12 setup.py`.

## Файлы
- `recipes.py` — рецепты, меню на неделю, покупки. `data.py` — программы тренировок.
- `botcore.py` — логика бота. `flask_app.py` — вебхук для PythonAnywhere. `morning.py` — утренняя рассылка.
- `fitbot.db` — все данные (вес, тренировки). Появится после первого запуска.
